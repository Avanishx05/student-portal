## Setup Instructions

### Prerequisites

* C++ compiler installed(g++ or clang++).
* [git](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git) installed on your machine.


### Cloning

* Connect to github with [ssh](https://docs.github.com/en/authentication/connecting-to-github-with-ssh).
* Open your terminal and run `git@github.com:Avanishx05/student-portal.git`.
* run `cd student-portal`
